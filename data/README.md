# Historical Defect Dataset

The `defects.csv` file is a small normalized seed corpus used to demonstrate the Milestone 1 RAG pipeline.

Required normalized fields:
- `bug_id`
- `project`
- `title`
- `description`
- `stack_trace`
- `resolution`

For the formal project dataset, replace/extend this file with the approved public Mozilla, Apache and Eclipse defect records from the specified source while preserving the normalized schema.
