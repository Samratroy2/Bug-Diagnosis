RETRIEVAL PIPELINE

How retrieval works

The backend creates semantic embeddings for prepared defect chunks and stores them in a FAISS vector index.

A submitted bug is embedded with the same model, searched against the index and ranked by similarity.

Similarity thresholds

≥ 82% Duplicate candidate
65–81.9% Related defect
< 65% Weak / unmatched
