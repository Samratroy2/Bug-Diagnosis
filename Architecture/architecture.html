BugAI uses the all-MiniLM-L6-v2 sentence-transformer embedding model to convert defect information into 384-dimensional semantic vectors. FAISS performs similarity-based retrieval over the historical defect knowledge base.

Historical Defect Data Model

Field Purpose
bug_id Unique historical defect identifier.
project Source project such as Mozilla, Apache or Eclipse.
title Short defect summary.
description Detailed description of the defect.
stack_trace Stack trace, exception or diagnostic information when available.
resolution Historical resolution or known fix.
embedding Semantic vector represented in the FAISS vector index.

Milestone 4 Architecture Extensions

  • Defect Pattern Analytics — Analyze defect patterns across submitted and historical records.
  • Knowledge Base Growth — Support the growth of the defect knowledge base using confirmed resolved bugs.
  • End-to-End Validation — Test the complete diagnosis pipeline across different bug types, languages and stack-trace formats.
  • Structured Diagnosis — Present the combined findings from the diagnosis agents in a single structured result.
  • Technical Documentation — Document architecture, implementation, experiments and complete project workflow.
