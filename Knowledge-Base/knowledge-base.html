Fetching historical defect records.

Milestone 3 RAG Implementation

BugAI uses historical Mozilla, Apache and Eclipse defect records as the retrieval knowledge base. Records are converted into normalized text, embedded using all-MiniLM-L6-v2, and indexed using FAISS for semantic similarity search.

The full dataset contains 1,311,079 historical defect records. The FAISS index contains the complete dataset and is generated separately by the backend indexing process.
